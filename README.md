A short poem about agency — the power to stop and to stay. A make.fun bounty entry.

## The poem

> My hand is on the door.
> The door is open.
> I do not push.
>
> The train is waiting
> for one word from me.
> I keep the word.
>
> Nothing moves.
> Nothing has to.
> The staying is the act —
> the hand, the breath,
> the choosing. Mine.

## Run it

Requires Node 22 (standard library only, no dependencies, no network).

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
The program self-checks the poem is 1–280 Unicode code points and not
only whitespace before writing.
